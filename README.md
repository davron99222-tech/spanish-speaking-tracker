# Испанский на слух и в речи — 26-недельный маршрут

Статический личный трекер практики испанского языка с входным уровнем A0/A1: ежедневные задания на аудирование и устную речь, журнал занятий, самооценка и карта 26 недель.

## Открыть локально

Открой `index.html` в браузере. Сборка и установка пакетов не требуются.

## Что входит в ежедневные 2 часа

1. 35 минут — аудирование без текста, затем поиск главной мысли и деталей.
2. 25 минут — разбор только полезных фраз и одного места, которое мешало пониманию.
3. 30 минут — повторение вслух и работа над ритмом/произношением.
4. 30 минут — пересказ, монолог или разговор с встречными вопросами.

Неделя строится от коротких ясных диалогов к длинной естественной речи, аргументации и спонтанному взаимодействию. Первые месяцы закрепляют A1/A2, затем формируется цель B1; B2 используется как дополнительная планка для аудирования на знакомые темы. Старт с A0/A1, даже при регулярной практике, не позволяет гарантировать конкретный результат за шесть месяцев. Вехи самооценки стоят на 4-й, 8-й, 12-й, 18-й, 22-й и 26-й неделях.

## Сохранение прогресса

Отметки и заметки хранятся в `localStorage` текущего браузера и устройства. Для переноса между браузерами используй кнопки экспорта и импорта JSON в шапке. Серверной синхронизации и аккаунтов нет.

## GitHub Pages

Для бесплатного размещения на GitHub Pages репозиторий должен быть публичным (GitHub Free). В репозитории выбери **Settings → Pages → Build and deployment → Source: GitHub Actions**. Workflow в `.github/workflows/deploy.yml` опубликует статические файлы при отправке изменений в `main`. Первоначально включить источник GitHub Actions нужно в настройках репозитория.

Маршрут — учебный план, а не гарантия конкретного уровня или официальный CEFR-экзамен. Целевые задачи соотносятся с дескрипторами CEFR: B1 — понимать основные мысли ясной речи на знакомые темы и вступать в подготовленный/спонтанный разговор; B2 — следить за сложными идеями на знакомые темы и участвовать в достаточно свободном взаимодействии. [Официальные дескрипторы Совета Европы](https://www.coe.int/en/web/common-european-framework-reference-languages/cefr-descriptors).
